# Інсайдер

Настільна гра «Інсайдер» для компанії на одному Android-телефоні.
Хост запускає застосунок — на телефоні піднімається локальний сервер. Інші гравці
сканують QR-код і грають у звичайному браузері; встановлювати нічого не треба.
Інтернет не потрібен — тільки спільна Wi-Fi мережа або точка доступу хоста.

**Завантажити:** [останній реліз](https://github.com/sokolovskiy0103/Insider/releases/latest) → `Insider.apk`.

## Як грати (4–8+ гравців)

1. **Ролі.** Кожен бачить свою роль. Майстер (по черзі) і таємний Інсайдер знають слово.
2. **Вгадування** (за замовчуванням 5 хв). Гравці ставлять Майстру питання «так/ні».
   Коли хтось назве слово, Майстер на своєму телефоні відмічає, хто вгадав.
   Якщо час вийшов — програють усі, навіть Інсайдер.
3. **Обговорення.** Триває стільки ж, скільки йшло вгадування (пісочний годинник перевертається).
4. **Голосування 1.** Чи той, хто вгадав, — Інсайдер? Більшість «так» → розкриття.
5. **Голосування 2** (якщо «ні»). Кожен вказує на підозрюваного. Нічию вирішує голос Майстра.

**Очки:** спіймали Інсайдера — +1 кожному гравцю й Майстру; Інсайдер вислизнув — +3 йому.

## Архітектура

- `GameServer.kt` — Ktor (CIO) HTTP + WebSocket на порту 8080+, роздає веб-клієнт з `assets/web`.
- `Game.kt` — уся логіка гри; кожен клієнт отримує власний знімок стану (слово бачать лише Майстер та Інсайдер).
- `GameService.kt` — foreground service, щоб гра не падала у фоні; wake/wifi locks.
- `assets/web/` — один клієнт для всіх (`/` для гравців, `/host#token` у WebView хоста).
- `assets/web/words.json` — список слів.

CI (`.github/workflows/build.yml`) на кожен push у `main` запускає тести, збирає підписаний APK
і публікує реліз `v1.0.<run>`. Ключ підпису лежить у репо, тож нові версії ставляться поверх старих.
